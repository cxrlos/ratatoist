# ratatoist-tui

ratatoist-tui has moved. ratatoist is now one crate, [`ratatoist`](https://crates.io/crates/ratatoist):

```sh
cargo install ratatoist
```

This is the last release of `ratatoist-tui`. Earlier versions stay installable, but they get no updates. The source lives at https://github.com/cxrlos/ratatoist.
